# Aspire 17 presentation outline

## Audience and purpose

Application developers, platform engineers, and Aspire users deciding whether and how to upgrade to Aspire 17. The takeaway is to treat this release as a major resource-first and multi-language shift, while reviewing migration breaking changes before upgrading.

## Selected sequence

1. **Aspire 17.0: the resource-first release** — release scope and source repositories.
2. **A redesigned dashboard** — resource table, overview, terminal page, graph, traces, metrics, and Mermaid export.
3. **A sharper CLI and agent workflow** — shell completion, secrets, team configuration, tray companion, and VS Code tools.
4. **Polyglot AppHosts and stable deployment** — preview Go support, AppHost updates, stable Kubernetes and AKS packages.
5. **Upgrade before you ship** — .NET 10 baseline, deprecated project registration and SDK, removed integrations, package migration, and Helm 4.
